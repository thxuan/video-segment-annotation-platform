# 故障排查

启动命令见 [README](../README.md)，测试入口与隔离边界见 [测试说明](automation-tests.md)，业务规则见 [架构约定](architecture.md)。先区分进程、数据库、文件和浏览器状态，再根据对应日志处理。

## 启动、配置与依赖

| 症状 | 检查与处理 |
| --- | --- |
| Docker / WSL 访问失败 | 先在正常用户终端确认 Docker Desktop / Linux 引擎已启动；受限进程的 E_ACCESSDENIED 不代表宿主引擎不可用 |
| 端口冲突 | Compose Web 8080、API 8000、业务 DB 55433；本地 Vite 5173。容器 API 与本地 API 不同时占用 8000，不终止未知进程 |
| 登录失败 | 先执行演示导入，初次密码见 `.env` 的 APP_DEMO_PASSWORD；四个演示账号初次同密码。重复 seed 保留已有密码和任务状态，改 `.env` 不会重置数据库账号 |
| 数据库密码不符 | `.env` 新密码不会更改已有数据卷密码；使用原配置或明确管理账号，不删卷解决 |
| 数据库结构缺失 | 本地后端执行 alembic upgrade head 并重启；Compose API 启动自动迁移。ready 检查数据库、任务版本和片段表；不因缺迁移删除原数据 |
| ffprobe 缺失 | Docker API 已包含；本地按 README 安装或配置 APP_FFPROBE_BINARY。宿主 Windows 路径不用于容器，Compose 覆盖为容器内 ffprobe |
| 依赖安装慢 / 失败 | 保持锁文件安装，查看具体失败源；Docker 使用 BuildKit pip / npm 缓存，pip 有有限重试与 pip check。不要多个安装器同时写锁文件 |
| 浏览器来源被拒绝 | 使用 README 中 localhost / 127.0.0.1；新来源需配置 APP_ALLOWED_ORIGINS。公网配置 HTTPS 和 APP_COOKIE_SECURE |

数据库镜像为 `pgvector/pgvector:0.8.0-pg17`，不启用向量扩展；有镜像时 --pull never 避免拉取。宿主正常终端使用自身 Docker 配置；受限工具读取失败时可用项目忽略的 `.cache/docker` 配置目录，语法检查不等于容器运行。

## 视频下载、发布与播放

- **下载截断**：prepare_demo.py 检查 Content-Length 和 MP4 的 ftyp / moov / mdat 顶层数据块。文件有 MP4 文件头也可能尾部缺失，ffprobe 会报 error reading header。重新下载完整文件并验证后再替换失败副本，不覆盖已有业务视频；手动下载位置见 README。
- **发布失败**：检查有效 MP4、单文件默认不超过 512 MB、ffprobe 可执行、视频目录可写。后端调整上限时同步前端和 Nginx；空文件、伪 MP4 或探测失败不能产生可领取任务。
- **结果待核对**：网络 / 5xx 或应答不明确时先查看任务列表，确认是否已创建再决定重试。批量成功项不应重发；文件系统与数据库不共用事务，强制中断可能遗留孤立文件，不能直接批量删除来修复。
- **不能播放或拖动**：先核对任务可见性、文件存在、浏览器编码支持、Content-Type 和 Range 206 / 416；401 是会话问题，404 可能是权限或文件问题。帧索引失败先重试，仍可秒数 / 百分比定位，不声称帧精确导出。

## 编辑、保存与统计

- **自动保存暂停**：非法 / 未完成输入不上传；网络失败或冲突后暂停自动重试。保留内容，恢复网络后手动重试；409 先导出 JSON，再确认载入最新内容，不改 expected_revision 强行覆盖。
- **只有本机备份**：不代表服务器已保存，确认保存位置提示。备份限同源、同账号、同任务及编辑器实例；localhost、127.0.0.1、不同端口不共享。清理站点或无痕会话关闭可能丢失本机备份。
- **恢复草稿**：先选择恢复或服务端版本；恢复不自动上传，保留原版本。JSON 目前仅供人工核对，不支持自动导入或冲突合并；存储不可用时仍可手动保存到服务器。
- **提交结果不明**：冻结编辑并保留原请求，恢复后重试相同内容 / 版本或载入服务端确认；未确认成功不显示庆祝。不要新建另一任务代替核对，也不要修改已提交片段。
- **统计不一致**：只统计 submitted，按北京时间提交日归账；草稿、创建日和保存日不决定有效时长。核对原始任务、片段及查询条件，不能手工改汇总掩盖问题。
- **统计日期未生效**：输入与已应用条件分离，点击查询才应用。模块往返会保留，浏览器刷新或换账号会初始化；接口失败显示错误而非零。
- **换账号后权限检查失败**：重新从 /api/auth/me 获取当前会话 CSRF；401 或错误字段 422 不能代替业务权限拒绝 403 / 404。不要输出令牌或密码到共享日志。

## 测试与容器构建

- 完整回归用 55435 临时库，日期独立入口用 55434，原业务库 55433 不受影响。测试锁遗留时先核实 PID 已退出；不能删除业务卷或停止未知服务。
- pytest 临时文件按运行放入 `.cache/pytest/` 或本次报告目录；旧目录权限错误时使用统一入口分配新目录，不清理原验收数据。
- Docker 构建曾在 Debian 下载返回 502 / EOF，也曾因后续 Python 下载过慢达到总超时。区分上游网络错误与版本冲突，先看失败源；后续原源恢复，已有最终 Linux 构建通过。没有通过禁用 TLS 或改全局代理处理。
- 镜像构建与启动分别记录；每个镜像默认 1200 秒，可用 compose --build-timeout 1800 调整，应用启动另限时。延长总预算不能修复持续 HTTP 5xx；缓存构建耗时不能当作无缓存基准。
- 真实上传后播放视频可能回收 Chromium 调试缓存中的响应体，出现 inspector cache evicted。测试以独立认证请求核对实际持久化结果，不依赖易被回收的上传应答缓存，不模拟成功。
- 默认直接 pytest 的数据库 / 日期用例会 skipped，需使用显式专用入口；运行失败或跳过不能视为通过。最新结果、日志路径与复跑命令见 [测试说明](automation-tests.md)。
