# 架构与业务约定

启动与账号见 [README](../README.md)，验证方法见 [自动化测试](automation-tests.md)，人工操作见 [验收清单](acceptance.md)。本文记录当前实现与设计取舍。

## 技术栈与模块

采用前后端分离、模块化单体：React / TypeScript / Vite 前端，FastAPI / SQLAlchemy 后端，PostgreSQL 17；Alembic 管理数据库结构，Docker Compose 提供运行环境。依赖版本记录在前端 package-lock.json 和后端 requirements.lock 中。

| 位置 | 职责 |
| --- | --- |
| `src/frontend/src/App.tsx` | 登录、角色导航、任务列表及工作区 |
| `PublishTask.tsx`、`Statistics.tsx` | 任务发布队列、管理员每日统计 |
| `TaskWorkspace.tsx`、`AnnotationTimeline.tsx` | 视频播放、片段编辑、时间轴及保存恢复 |
| `PersonalStatistics.tsx`、`SubmissionCelebration.tsx` | 个人统计、提交成功反馈 |
| `src/backend/app/auth.py`、`security.py` | 登录会话、来源与 CSRF 校验 |
| `tasks.py`、`workflow.py`、`rules.py` | 任务权限、状态变化、片段规则及并发保护 |
| `stats.py`、`media.py` | 统计聚合、视频探测、鉴权播放与帧索引 |
| `models.py`、`migrations/` | 数据模型、数据库约束与版本化迁移 |

前端文件名相对 `src/frontend/src/`，后端文件名相对 `src/backend/app/`。视频文件保存在受控目录，数据库只保存文件标识和元信息，不存视频二进制。

## 业务规则与权限

- 平台管理员跨租户发布任务、查看统计；标注员属于一个租户，只能访问本租户待领取任务及本人任务。同租户其他人已领取的任务也不可读取。
- 一条任务关联一个视频，由一名标注员领取。批量发布为每个视频创建独立任务，不提供多视频同步时间轴。
- 片段使用整数毫秒和半开区间 `[start_ms, end_ms)`，满足 `0 ≤ start_ms < end_ms ≤ duration_ms`；同任务片段不得重叠，首尾相接允许，最多 1000 段。后端和数据库共同验证，不依赖前端输入。
- 空草稿可以保存，空片段列表不能提交。提交后片段、领取人和首次提交时间锁定，管理员不代标注员编辑。
- 有效时长为已提交任务各片段长度之和；草稿排除，多个片段不重复计算任务数。按服务端提交时的北京时间归账，数据库保存 UTC；日期范围包含首尾业务日，最多 366 天。
- 片段是否有用由标注员判断；不实现自动识别或复审。

| 操作 | 平台管理员 | 标注员 |
| --- | --- | --- |
| 发布任务、选择租户、查看每日统计 | 允许 | 禁止 |
| 列表、详情、视频、帧索引 | 全部租户 | 本租户待领取任务及本人任务 |
| 领取 | 禁止 | 本租户待领取任务 |
| 保存、提交 | 禁止 | 本人领取且处于标注中的任务 |
| 已提交任务 | 全部只读 | 本人只读 |
| 个人统计 | 不提供 | 仅本人及当前租户 |

身份从服务端登录会话取得。对象不可见统一返回 404；角色禁止返回 403；匿名或过期会话返回 401；状态或版本冲突返回 409；非法字段和片段返回 422。

## 数据与状态变化

实体包括 Tenant、User、Task、Segment 和 LoginSession。Task 保存视频标识、实际时长、状态、领取人、提交时间和 revision；Segment 保存起止毫秒。数据库包含片段区间检查与 GiST 排斥约束、领取人及租户的复合外键、任务状态一致性检查。

任务状态为 `available → in_progress → submitted`：

1. **领取**：任务行锁内核对权限和待领取状态，只有一人成功；竞争或重复领取返回 409。
2. **保存**：携带完整片段和 `expected_revision`，锁内复核权限、状态和版本，在一个事务中替换片段并递增 revision；失败回滚。
3. **提交**：同一事务保存当前片段、设置 submitted 和首次提交时间。与保存共用任务锁，旧版本不能覆盖；提交成功后相同规范化内容重试返回原结果，不改变时间、版本或统计，不同内容重试返回 409。

迁移 `0001_foundation` 创建基础结构，`0002_annotations` 增加片段、revision 和相关约束，安装 PostgreSQL 自带的 btree_gist 扩展。`alembic upgrade head` 更新结构；演示种子命令另行创建 2 个租户、4 个账号、7 个任务，重复执行保留已有密码和任务状态。

## 认证与接口

密码使用 Argon2 散列；随机会话令牌只在数据库保存摘要，通过 HttpOnly / SameSite=Lax Cookie 传递，登出撤销服务端会话。写接口校验允许的 Origin 和会话 CSRF，不将令牌保存在 localStorage。公网部署需另外启用 HTTPS、Secure Cookie 和可信来源。

| 接口 | 行为 |
| --- | --- |
| `POST /api/auth/login`、`GET /api/auth/me`、`POST /api/auth/logout` | 登录、当前身份、登出 |
| `GET /api/tasks`、`GET /api/tasks/{id}` | 按权限筛选和分页、任务详情 |
| `POST /api/tasks?title=...&tenant_id=...` | 管理员发布，原始 MP4 请求体 |
| `POST /api/tasks/{id}/claim` | 原子领取 |
| `PUT /api/tasks/{id}/segments`、`POST /api/tasks/{id}/submit` | 保存、提交，携带 revision 和片段 |
| `GET /api/tasks/{id}/video`、`GET /api/tasks/{id}/frames` | 鉴权播放 / Range、按需帧时间索引 |
| `GET /api/stats/daily`、`GET /api/stats/tasks` | 管理员每日汇总、分页追溯任务 |
| `GET /api/stats/me` | 标注员个人统计 |

列表在权限及筛选条件内按待领取、标注中、已提交排序，同状态按创建时间降序和 ID 升序稳定分页。视频时长由 ffprobe 读取，视频路径不得越过存储目录。帧索引按实际时间戳定位而非平均帧率估算；按需缓存、限时限量，失败可重试，不伪装为 1 毫秒帧步进。接口以毫秒存储，不承诺帧精确剪辑导出。

## 发布队列与文件一致性

统一“发布任务”入口支持一个或多个 MP4；每个视频可编辑标题，顺序复用单任务接口，单文件默认上限 512 MB。开始后锁定本批租户，成功项只读且不参与重试；状态筛选只改变显示，不改变候选队列。列表独立滚动，按视口预留底部操作栏空间，错误详情默认折叠。

明确的校验失败保留该项并继续其他合法项；网络中断、5xx 或成功应答无法解析时暂停，标记“结果待核对”，人工确认后才允许重试。401 / 403 停止队列。上传中禁止应用内离开，未完成离开提示；队列不跨刷新保留，不支持后台上传或断点续传。

文件先写临时文件，经真实探测后重命名并创建任务；提交前失败清理文件。文件系统与数据库不是同一事务，提交应答丢失时保留最终文件，避免删除已经成功任务的视频。尚未实现发布幂等键或孤立文件自动清理，强制终止后应先核对任务列表与文件再处理。

## 编辑、导航与统计体验

- 前端编辑与服务端持久化状态分开。合法修改停止约 1.5 秒后自动保存，可按账号关闭；一次只发一个写请求。非法 / 未完成输入不上传，失败或 409 暂停自动保存并保留输入。
- 本机草稿按来源、账号、任务和编辑器实例隔离，保存原始输入、原版本及待完成选段，不存身份凭据。恢复需显式选择，不自动上传，也不绕过版本检查。JSON 导出用于人工备份，不支持自动导入或冲突合并。
- I / O 从空白处开始新增片段，从已有半开区间内开始则锁定并替换该片段；O 校验通过前不改原片段，冲突不合并或推移邻居。支持最多 100 步撤销重做，“重新标注”确认清空且可撤销。
- 提交结果不明时冻结编辑，允许重试原内容 / 原版本或载入服务端状态。未保存离开确认，已提交任务只读。完整键位及复验见 [验收清单](acceptance.md)。
- 主题为炭黑 / 紫色深色与纸白 / 灰绿 / 深青绿浅色，按浏览器来源保存并跨同源标签同步；切换不重建编辑器或写业务数据。侧栏与任务菜单独立；“全部任务”入口在无进行中任务时仍可用。
- 管理员首次访问每日统计后，在同一工作区切到任务管理、发布和详情再返回，保留日期 / 租户输入、已应用条件、展开任务页码；输入只有点击查询才应用。浏览器刷新、退出或切换账号后重新初始化。接口失败显示错误，不显示假零。
- 个人统计四项汇总始终基于本人全部历史 / 北京时间今天，不随热力图范围变化；默认滚动最近 365 天，历史年份按 1–12 月完整展示，只允许已结束年份。大数缩写向零截断，悬停 / 聚焦 / 点击可查看完整毫秒值。
- 服务端确认提交成功后才显示庆祝弹窗并刷新统计；刷新已提交任务不重播。动效可关闭，支持减少动态效果，统计读取失败不伪造累计数。

## 实现边界

不包含注册 / 账号管理、任务转让或释放、复审退回、提交后修改、远程 URL 导入、手动旋转视频或多视角同步。演示任务复用同一 Push-T 文件，不代表生产视频跨租户共享。当前为本地演示配置，未线上部署；未进行大规模负载、长期稳定性、多浏览器矩阵或真实设备全屏验证。
