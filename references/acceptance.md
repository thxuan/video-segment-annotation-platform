# 人工验收清单

按 [README](../README.md) 启动并导入演示数据；业务口径见 [架构约定](architecture.md)，自动化覆盖与复跑见 [测试说明](automation-tests.md)。以下是可重复执行的人工检查，不将自动化通过等同于用户已验收。

## 准备与结果记录

- 使用 admin、a1、a2、b1；初次密码见本机 `.env` 的 APP_DEMO_PASSWORD。同一轮操作保持相同来源地址，localhost 与 127.0.0.1 不共享 Cookie 和本机存储。
- 每轮新发布标题带“验收-”的任务，避免复用已提交任务。演示文件为 `storage/videos/pusht-demo.mp4`，较长时间段示例要求视频至少 120 秒。
- 两个不同账号用不同浏览器或普通 / 无痕窗口；两个普通标签页共享登录，不能模拟两名用户。测试同一账号版本冲突时才使用两个普通标签页。
- 记录提交号、账号、测试任务 ID、操作、预期及实际结果；统计比较操作前后的增量，不要求已有环境从零开始。发现问题保留 Network 响应，不删除数据库卷重置。
- 第一至五步曾获用户验收认可；最终视觉、真实设备体验与整体交付仍待用户确认。复测结果另行记录，不能沿用历史验收替代本轮结果。

## 核心闭环

1. admin 在“发布任务”选择租户 A 和一个演示 MP4，修改标题后发布；等待完成，再点“查看任务”，预期待领取且视频可播放、可拖动定位。
2. a1 登录默认看到全部可访问任务，进入新任务并“领取并开始标注”；关闭自动保存，添加 `[10,30)` 秒和 `[60,105)` 秒，合计 `00:01:05.000`。
3. 点击“立即保存”，确认“已保存到服务器”后刷新；片段仍在。管理员统计不计这份草稿。
4. 改为两段合计 70 秒，例如 `[10,35)` 与 `[60,105)`，不另点保存直接提交，核对确认摘要；预期提交当前内容并进入只读，刷新后不重复提交。
5. admin 查询北京时间的提交日期、租户 A，预期增加 70 秒和 1 个任务；展开该标注员任务，查看片段与实际提交内容一致。
6. b1 列表不可见该 A 任务，直接读取该任务详情、视频和帧接口也应 404。a2 不可访问 a1 已领取任务；admin 可查看但不能代其编辑。

## 发布与管理员统计

| 操作 | 预期 |
| --- | --- |
| 一次选择两个以上 MP4，修改各自标题 | 每个视频生成独立任务，租户和标题正确，逐个上传 |
| 放入 50 个以上文件，长文件名，切换状态筛选 | 仅列表内部滚动，汇总和操作可用，最后一条不被操作栏遮挡；筛选不改变上传队列 |
| 编辑标题，Enter / 失焦结束，Escape 撤销本次编辑 | 待发布 / 失败项可编辑，成功项只读；空白标题不能发布 |
| 混入空文件、伪 MP4 或不支持编码的文件 | 明确失败，不创建缺失视频的任务；其他合法项独立完成，重试不重复成功项 |
| 上传中连点发布、切租户或导航 | 不重复发队列；租户 / 文件和应用内离开受限，完成后可新建一批 |
| 网络中断、5xx、成功应答不明确 | 暂停并显示“结果待核对”，先核对列表再显式确认重试；不自动重发 |
| 修改日期或租户，点击查询 | 当前结果、汇总、表格和明细使用一致条件；失败显示错误，空数据才为零 |
| 查询后展开任务第 2 页，进入片段再返回 | 输入、已应用结果、展开行、页码、滚动和入口焦点保持 |
| 修改日期但未查询，切到任务管理 / 发布后返回 | 新输入保留，旧查询结果不自动改变；点查询才应用 |
| 查询有多任务、多片段和草稿的一天 | 只累计已提交片段，按任务计数；明细合计与汇总相等 |

## 规则、权限与并发

| 场景 | 操作与预期 |
| --- | --- |
| 初始演示权限 | 未进行业务操作时 admin 见 7 项，a1 / a2 各见 4 项，b1 见 2 项；管理员租户 A / B 分别 5 / 2 项 |
| 后端对象权限 | b1 直接请求 A 任务的详情、视频、帧、领取、保存、提交，带有效会话和 CSRF，均拒绝；a2 访问 a1 已领取任务同样拒绝 |
| 角色与会话 | 标注员不能发布、选择租户或查管理统计；管理员不能领取 / 保存 / 提交。退出后旧会话失效，换账号不显示旧缓存 |
| CSRF / Origin | 有效会话下省略 / 写错 CSRF 或使用不允许来源，写请求返回 403，数据不变；匿名 401 不能作为越权测试通过 |
| 非法片段 | 负数、零长度、倒序、超视频时长、小数毫秒、重复 / 包含 / 交叉区间均拒绝；上次合法草稿、revision 和状态不变 |
| 相邻与空值 | `[0,1000)`、`[1000,2000)` 毫秒允许；空草稿可保存，空提交拒绝，未填完的输入不上传 |
| 竞争领取 | a1 / a2 同时领取同一新任务，只有一个 200，另一方 409；失败者随后不能读取对方已领取任务 |
| 旧版本保存 | 同账号两标签同 revision，A 保存后 B 保存返回 409；B 输入保留，显式载入才替换，不自动合并 |
| 保存与提交竞争 | 同 revision 并发保存 / 提交只能一个成功；提交成功后迟到保存不能覆盖片段 |
| 相同提交重试 | 相同内容重复提交保持首次提交时间 / revision / 片段，统计只计一次；改内容重试或提交后保存返回 409 |
| 日期边界 | 在专用测试库验证跨日 / 月 / 年 / 闰日，按提交日而非创建或保存日归账；不用修改系统时钟或原验收库 |

真实竞争和跨日建议使用 [隔离自动化](automation-tests.md)，可重复验证数据库锁、事务与时间边界。

需要手动直接请求时，在已登录平台的浏览器控制台定义以下工具；每次切换账号重新定义。写请求仅对新建验收任务执行：

```javascript
window.checkSession = await fetch('/api/auth/me').then(r => r.json());
window.checkTaskId = '替换为本次验收任务UUID';
window.checkRead = async () => {
  const r = await fetch(`/api/tasks/${checkTaskId}`);
  return {status: r.status, body: await r.json()};
};
window.checkWrite = async (action, body) => {
  const r = await fetch(`/api/tasks/${checkTaskId}/${action}`, {
    method: action === 'segments' ? 'PUT' : 'POST',
    headers: {'Content-Type': 'application/json', 'X-CSRF-Token': checkSession.csrf_token},
    body: body === undefined ? undefined : JSON.stringify(body)
  });
  return {status: r.status, body: await r.json()};
};
```

`claim` 不带 body；保存 / 提交 body 为 `{expected_revision: 当前revision, segments: [{start_ms: 10000, end_ms: 30000}]}`。不要把字段错误 422 当成对象权限 404。并发保存 / 提交可用同一 payload 对两个 action 执行 Promise.all；该操作会真正改变测试任务。

## 编辑体验、快捷键与恢复

| 操作 | 预期 |
| --- | --- |
| 播放器或页面空白处左右键 / Shift 左右键 | 按全片 0.1% / 1% 定位，不越界；实际点击视频后恢复播放器上下文 |
| 时间轴播放位置和边界手柄左右键 / Shift 左右键 | 按实际帧索引移动 1 / 5 帧；索引失败提示重试，不冒充固定 1 毫秒 |
| 空格 | 工作台内无修饰键空格只播放 / 暂停，含按钮、输入、滑块、自动保存开关；长按只切一次。主题控件和模态框保留正常键盘行为 |
| I / O | 空白区开始新增，已有半开区间内开始锁定目标并替换；O 通过校验前不改原片段；冲突标出关联片段，原数据保持 |
| Shift I / O、Alt / Option X、Escape | Shift I / O 跳到边界；Alt / Option X 只取消待完成范围。Escape 在全屏只退出，不清范围 / 选中、不收菜单；文本编辑的 Escape 由控件处理 |
| Ctrl / Cmd S、Z、Shift Z，Ctrl Y | 保存、撤销、恢复撤销；文字输入保留原生文本撤销，保存在输入框仍可用；额外修饰键不能误触普通命令 |
| 增删改、聚焦片段、预览、重新标注 | 新行自动可见并聚焦，错误行清晰，片段与时间轴选择同步；清空须确认且可撤销，最多 100 步历史；预览到终点附近暂停 |
| 自动保存开关 | 默认开启，停止合法修改约 1.5 秒后保存；选择按账号保留。关闭后只更新本机备份，立即保存成功后才提示服务器已保存 |
| Offline 保存与恢复网络 | 失败保留输入、暂停自动重试；在线后手动重试。若服务端其实保存成功而应答丢失，则按 409 流程核对 |
| 原页刷新 / 重新进入 | 原详情和开关保持；未同步草稿先询问恢复 / 使用服务端，恢复保留原输入和 revision，不自动上传 |
| 提交结果不明 | 编辑和自动保存冻结，允许重试原内容 / 版本或载入服务端确认；未确认成功不庆祝 |
| 导出、离开与账号切换 | JSON 不含凭据，供人工备份而非自动导入；未同步离开提示，写入中禁导航；不同账号 / 实例不互相覆盖草稿 |
| 全屏、窄屏、侧栏 | 全屏仍可编辑同一时间轴，退出保留位置 / 选择；窄屏无整页横向溢出。侧栏与菜单独立，顶部图标只收放，空任务时仍可返回全部任务 |

## 主题、个人统计与提交反馈

- 登录、列表、工作台、发布、统计及全屏均可深浅切换，未保存输入和播放位置不丢失，不产生保存请求；刷新 / 重开 / 退出重登保持主题，同源标签同步，存储失败提示。
- 个人统计默认最近 365 天，历史年份按完整 1–12 月展示，包括闰年和中间空年份；不提供今年或未来年份。切范围不改变累计 / 今日汇总；无数据为零、接口失败提示重试。
- 大数字按万 / 亿或小时缩写并向零截断；悬停、键盘聚焦 / Enter、触屏点击查看完整值，时长精确到毫秒；Escape 或离焦收起，浮层在窄屏不越界。热力图支持方向键、Home / End、单日详情和局部滚动。
- 提交成功后暂停视频、只读并居中显示成果弹窗；完成 / Escape 留在详情，返回列表按钮可导航。动效开关与减少动态效果生效，刷新不重播；统计失败不编造累计数。
